# Results and interpretation

This source release does not bundle raw or synthetic images, per-image predictions, checkpoints, caches, or intermediate run trees. It is intended to provide the software, frozen image-level split specifications, and configuration needed to reproduce or extend the experiments. Results should be generated into a new local output directory and checked against the manuscript's stated run coverage.

The post-hoc internal follow-up split its former validation pool into model-selection and reporting subsets; those reporting images had been part of a previously examined validation pool. The four-seed external follow-up was partial, with 64 completed runs over four of seven planned arms. Neither follow-up establishes broad clinical generalisability or patient-level independence. Four-seed confidence intervals are imprecise and conditional on the fixed image cohorts. See the manuscript for the reported estimates and limitations.
